⚠️ Vùng nguy hiểm

Xóa vĩnh viễn toàn bộ bản ghi quét của mọi tài khoản. Không thể hoàn tác.

📦 Master data đơn hàng (chỉ quản trị viên)

File ĐƠN ĐẶT HÀNG TVS chuẩn: 1 đơn hàng (chỉ thị) = 1 PO cố định. Khi quét, app tự tra PO từ đây. Import lại file khi đơn hàng thay đổi; bấm Sửa để chỉnh từng dòng.

📦 Packing list (chỉ quản trị viên)

File PACKING_LIST_CLP_TVS chuẩn: mỗi chỉ thị có các khoảng thùng liên tục, mỗi khoảng cố định 1 size + số đôi/thùng. Khi quét, app tự tra số thứ tự thùng (đuôi mã QR) vào khoảng này để điền Size/PO chính xác 100% — không cần OCR hay chọn tay.
